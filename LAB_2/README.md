## Aim
To learn how to create a bare Git repository, connect it as a remote repository, push commits to it, and clone the repository.

## Requirements
- Git
- Visual Studio Code
- Windows PowerShell / Terminal

## Tasks Performed

### Task 1: Creating a Bare Remote Repository
- Created a bare repository named `html-remote`.
- Added it as the remote named `origin`.
- Verified the remote connection using `git remote -v`.

### Task 2: Pushing the Repository
- Pushed the local `master` branch to the remote repository using `git push origin master`.
- Verified that the branch was successfully pushed.

### Task 3: Cloning the Repository
- Cloned the remote repository into a new folder named `html-copy`.
- Checked the commit history using `git log --oneline`.
- Verified that both previous commits were available in the cloned repository.
