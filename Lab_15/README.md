## Aim
To understand responsive web design using mobile-first layouts, responsive images and CSS media queries.

## Requirements
- HTML

## Tasks Performed

1. **Mobile-First Design:** Created a responsive card layout that stacks vertically on smaller screens and displays side by side on screens 600px or wider.
2. **Responsive Images:** Used `max-width: 100%` and `height: auto` to make images adjust to different screen sizes.
3. **Responsive Typography:** Used CSS media queries to change the heading font size according to screen width.
